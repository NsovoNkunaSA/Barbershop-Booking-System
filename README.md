# Barbershop-Booking-System
A modern, full-stack barber shop booking application with real-time dashboard, service management, and appointment scheduling.
# Access the barbershop here:
https://nsovonkunasa.github.io/Barbershop-Booking-System/

https://images.unsplash.com/photo-1585747860715-2ba37e788b70?ixlib=rb-4.0.3&auto=format&fit=crop&w=1200&q=80

🚀 Features
Frontend
✅ Modern, responsive design with CSS Grid/Flexbox

✅ Dynamic service loading from API

✅ Interactive booking form with validation

✅ Real-time bookings dashboard

✅ Smooth scrolling animations

✅ Font Awesome icons integration

Backend
✅ Express.js REST API

✅ In-memory database (no SQL required)

✅ CRUD operations for bookings

✅ Revenue calculation

✅ Time slot conflict detection

✅ Error handling middleware

Business Features
📅 Appointment scheduling with date/time selection

💰 Automatic revenue calculation

📊 Real-time dashboard with today's bookings

⚠️ Duplicate booking prevention

📱 Mobile-responsive design

🎨 Professional barber shop aesthetic
